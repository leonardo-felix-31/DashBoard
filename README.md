📊 Análise Exploratória de Dados e Dashboard da Covid-19
🧾 Descrição
Este projeto tem como objetivo realizar uma análise exploratória de dados (EDA) sobre os impactos e evolução da Covid-19 com base em dados públicos. A iniciativa busca identificar padrões, tendências e insights relevantes a partir dos dados disponíveis, bem como apresentar essas informações de forma clara e interativa por meio de um dashboard visual no Google Data Studio.

🎯 Objetivos do Projeto
Entender a evolução da pandemia ao longo do tempo.

Analisar a distribuição de casos confirmados, recuperações e óbitos.

Investigar diferenças entre estados e regiões do brasil.

Apresentar visualmente os principais insights em um painel dinâmico.

🛠️ Ferramentas Utilizadas
Python: Linguagem principal para análise dos dados.

Pandas: Manipulação e limpeza dos dados.

NumPy: Operações numéricas e estatísticas.

Seaborn: Geração de gráficos estatísticos.

Matplotlib: Visualizações complementares e customizadas.

Google Data Studio: Criação do dashboard interativo para visualização dos dados.

📈 Resultados
A análise resultou na criação de gráficos e métricas que permitem:

Visualizar a evolução diária e acumulada dos casos.

Comparar o comportamento da pandemia entre diferentes regiões.

Identificar picos, quedas e tendências ao longo do tempo.

Apoiar a tomada de decisão com base em dados concretos.

O dashboard interativo facilita a compreensão das informações e está disponível para qualquer pessoa interessada em explorar os dados de forma intuitiva.
